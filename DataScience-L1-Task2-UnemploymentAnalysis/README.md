# Unemployment Analysis with Python

## 📌 Project Overview
This project analyzes unemployment rates in India, especially examining the impact of major events (such as the COVID-19 pandemic) on employment trends across different regions and time periods.

## 📊 Dataset
Unemployment rate data including:
- Region / State
- Date
- Estimated Unemployment Rate (%)
- Estimated Employed
- Estimated Labour Participation Rate (%)

## 🛠️ Tech Stack
- Python
- Pandas, NumPy
- Matplotlib, Seaborn, Plotly (visualization)

## 🔍 Workflow
1. **Data Cleaning** — handled missing values, fixed column names, and converted date formats.
2. **Exploratory Data Analysis (EDA)** — analyzed unemployment trends over time and across regions.
3. **Visualization** — created time-series plots, bar charts, and region-wise comparisons to highlight trends and anomalies (e.g., spikes during COVID-19 lockdowns).
4. **Insights** — identified regions/periods most affected by rising unemployment.

## ✅ Key Insights
- Unemployment rates showed a sharp spike during the COVID-19 lockdown period.
- Significant variation in unemployment rates was observed across different states/regions.
- Labour participation rate trends correlated with unemployment fluctuations.

## 📁 Files
- `Unemployment_analysis.ipynb` — Jupyter notebook with full analysis and visualizations
- `README.md` — Project documentation

## 🚀 How to Run
1. Clone this repository
2. Install dependencies: `pip install pandas numpy matplotlib seaborn plotly`
3. Open `Unemployment_analysis.ipynb` in Jupyter Notebook / VS Code and run all cells
