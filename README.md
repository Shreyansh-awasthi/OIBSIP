## 🚀 Projects

| # | Project | Description | Tech Stack |
|---|---------|-------------|------------|
| 1 | [Iris Flower Classification](./DataScience-L1-Task1-IrisClassification) | Classifies iris flowers into 3 species using ML based on sepal/petal measurements | Python, Scikit-learn, Pandas |
| 2 | [Unemployment Analysis](./DataScience-L1-Task2-UnemploymentAnalysis) | Analyzes unemployment trends in India, including COVID-19 impact | Python, Pandas, Seaborn, Plotly |
| 3 | [Car Price Prediction](./DataScience-L1-Task3-CarPricePrediction) | Predicts used car selling prices using regression models | Python, Scikit-learn, Pandas |

Each project folder contains:
- 📓 Jupyter Notebook with full code and analysis
- 📄 A dedicated `README.md` explaining the project in detail
- 📊 Visualizations and model outputs (where applicable)
